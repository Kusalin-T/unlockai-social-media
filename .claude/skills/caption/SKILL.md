Write captions in the user's brand voice. **All captions must be in Thai.** Talk to the user in Thai.

## Steps

1. Always read `brand/brand.md` first (if missing → invite them to run `/brand`).
2. Know before writing (if the user hasn't said, ask once, briefly):
   - What the post is about / what photo or video there is
   - Which platform it's going on
   - What the audience should do next (DM? tap a link? share? comment?)
3. Write **3 variants** to choose from. Each one:
   - **First-line hook** — stop the scroll in one line (question / number / myth-buster)
   - Short, readable body with line breaks
   - **One clear CTA** matching what the user wants
   - Hashtags: mixed Thai + English, 5–10 (IG/TikTok) / 1–3 (Facebook)
4. The 3 variants must be genuinely different, e.g. storytelling / direct-sell / engagement-question.
5. Once the user picks one → polish per their notes. If they asked for several posts, save them together as a file in `output/`.

Never break the brand voice. Never use words listed under "Never" in `brand.md`.
